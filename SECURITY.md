# Security

Report a suspected vulnerability privately through the ExaCopy repository's
Security tab if private reporting is available. Otherwise contact a
repository maintainer privately and request a secure channel. Keep
vulnerability details out of public issue reports during triage.

Include the affected revision, platform and filesystem, impact, a minimal
reproduction using disposable data, and any relevant redacted logs. Keep
credentials, recovery keys, private paths and user file contents out of the
report. See the [repository Security tab](https://github.com/replicraft/ExaCopy/security).

The [foundation](docs/foundation.md) and [platform
work package](docs/local-adapter.md) define the current preservation and
durability claims. [Contract versioning](docs/architecture/contract-versioning.md)
defines how incompatible artifacts and migrations must preserve recovery.
Dependency review follows the [supply-chain policy](supply-chain/README.md).
