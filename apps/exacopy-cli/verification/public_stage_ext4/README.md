# Native public-stage composition fixture

The fixture measures one task-owned source with the Linux public planner,
admits the exact canonical Plan and page, stages into an absent target's
private job, then reopens the job under a separate native read lease. The
inspector checks the exact public and private Plan digests, signed owner,
selected profile, journal prefix and independent stage read-back. The target
remains absent. The fixture uses a public synthetic signer and operates only
on files it creates.

The same test refuses a substituted Plan commitment before bootstrap and
refuses the original job under a wrong key or the ordinary recovery reader.
A same-length change to the original source inode passes fresh private
observation but fails the original public stream commitment. The inspector
reports the retained partial stage. The fixture then writes a torn frame
prefix to its own journal and checks that inspection retains the original
verified boundary and reports reconciliation. A late incumbent refuses a
fresh stage attempt before bootstrap. The final checks compare incumbent
identity and bytes, both staged streams and the torn journal.

Run from the exact clean revision with locked dependencies already cached.
Provision the pinned APFS and repaired transport sources using the repository
source tools. The runner checks them on both sides of the build and test.
Use an unconfigured Cargo cache and checkout.
Select a canonical, owner-protected temporary parent on the current writable
whole ext4 root mount on Linux x86-64. Use an ordinary unprivileged actor
with the native identity mappings and no live capabilities.

```sh
python3 -B apps/exacopy-cli/verification/public_stage_ext4/test_runner.py
PYTHONDONTWRITEBYTECODE=1 python3 apps/exacopy-cli/verification/public_stage_ext4/run.py \
  --revision "$(git rev-parse HEAD)" --temporary-parent "$RUNNER_TEMP"
```

The canonical hosted workflow runs this profile on an exact push to main.
It retains the native result and build and run transcripts.
The runner verifies the exact ignored libtest selector and held
Cargo artifact with no default features. It records the compiler, selection,
process drain, boot, mount and namespace observations, input hashes and
cleanup. It prints the retained evidence directory. A missing native
prerequisite yields exit 77. The runner prepares the evidence before
any native test effects.

The scope includes private staging, read-only restart inspection, and checked
transfer components under fixture-only authority. The two component cases
publish only into absent names in owned fixtures. They check completed receipt
commit and refused receipt commit, including exact retained artifact bytes.
This covers R-007, R-013, R-015 and R-017 and INV-001–004/009/019 at those
boundaries. The torn suffix is induced in a fixture-owned journal. Public apply
command dispatch, independently enrolled SDK execution, process-crash and
power-loss qualification require separate acceptance.
