# Contributing

Read [AGENTS.md](../AGENTS.md), the [architecture](architecture.md) and the
[engineering standards](engineering/standards.md). Select a bounded
work package and identify the affected contracts, acceptance cases and
verification obligations. Keep existing customer data and pre-existing
contributor changes intact.

Run the [workspace and scoped checks](testing.md). Update the owning
specification and documentation with observable behavior and actual
supported profiles. Retain failure evidence and include the regression
with the fix. Keep commits focused and use Conventional Commit subjects.
Publishing or pushing requires explicit authorization.

Contributions use the project's [Apache-2.0](../LICENSE) license. Record the
origin and license of imported code or fixtures. Report vulnerabilities
through the [security reporting process](SECURITY.md).
